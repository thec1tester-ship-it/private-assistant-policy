Kebijakan Privasi & Keamanan

Tanggal Berlaku: 7 Nopember 2026
Pengembang Resmi: THE C1 Technology

1. Prinsip Utama Privasi (100% Lokal)

Data Anda adalah milik Anda. Seluruh kata sandi, catatan, dan rekam keuangan disimpan secara lokal di memori perangkat Anda tanpa pelacakan server terpusat.

2. Standar Enkripsi AES-256 GCM

Kata sandi dan PIN dilindungi menggunakan enkripsi tingkat militer AES-256 GCM yang terintegrasi langsung dengan Android KeyStore resmi.

3. Transmisi Data Layanan AI via HTTPS

Hanya teks pertanyaan obrolan AI yang dikirimkan via HTTPS ke server penyedia AI (Gemini, OpenAI, DeepSeek, Groq, Claude). Data brankas sandi dan catatan TIDAK PERNAH dikirimkan.

4. Bebas Izin Storage Berlebih (SAF Only)

Aplikasi ini tidak meminta izin membaca galeri foto/media perangkat Anda secara luas. Ekspor dan impor cadangan menggunakan Storage Access Framework (SAF) resmi.

5. Komitmen Anti-Penjualan Data

Kami menegaskan tidak pernah menjual, menyewakan, atau membagikan data pribadi atau keuangan Anda kepada pihak ketiga untuk iklan atau pemasaran.

6. Hak & Kontrol Pengguna Atas Data

Anda berhak menghapus riwayat obrolan AI, kredensial, catatan, atau menghapus seluruh data aplikasi kapan saja via Pengaturan Aplikasi Android.
